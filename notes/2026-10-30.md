## Key points
- `||` falls back on any falsy value (0, '', false). `??` falls back only on `null` and `undefined`.
- `??` returns the right side when the left is nullish: `null ?? 0 ?? 5` is `0`.
- `?.` short-circuits the whole rest of the chain: `a?.b.c.d` stops at `a` if it is nullish.
- Mixing `??` with `||` or `&&` without parentheses is a SyntaxError. A SyntaxError stops the whole file at parse time, so not even earlier lines print.
- Default parameters and destructuring defaults apply only for `undefined`, not `null`.
- `??` is not always the fix: `Number(null)` is `0` and `Number('abc')` is `NaN`, so `Number(v) ?? 20` never falls back. Validate instead.
- Logical assignment: `a ||= b`, `a &&= b`, `a ??= b` only assign when needed (the setter is not called otherwise).
- Helpers like `setIn`/`merge` must block `__proto__`, `constructor` and `prototype` keys (prototype pollution).
