## Key points
- Function declarations are hoisted with their body. A `var` function expression is hoisted as `undefined`, so calling it early gives "TypeError: x is not a function". `let`/`const` give the TDZ error.
- The name of a named function expression is visible only inside its own body: `var bar = function baz() {}` means `baz` is not defined outside.
- Arrow functions have no own `this`, `arguments` or `prototype`, and can't be called with `new` ("TypeError: Make is not a constructor").
- Arrow `this` comes from where the arrow is written. Regular function `this` comes from how it is called (`obj.method()` means `this` is `obj`).
- Default params apply only for `undefined`, are evaluated on every call (`list = []` is fresh each time) and can use earlier params.
- Rest params give a real array and must come last. `arguments` is array-like, counts every passed argument (not defaults) and doesn't exist in arrows.
- `fn.length` counts only the params before the first default or rest param.
- `typeof` always returns a string: write `'undefined'`, not `undefined`.

```js
function once(fn) {
  let called = false;
  let result;
  return function (...args) {        // regular function: gets `this` from obj.getX()
    if (!called) {
      called = true;
      result = fn.apply(this, args); // forwards `this` and all arguments
    }
    return result;
  };
}
```

```js
function pipe(...functions) {
  return function (...args) {
    if (functions.length === 0) return args[0]; // identity
    const [first, ...rest] = functions;
    return rest.reduce((acc, fn) => fn(acc), first(...args));
  };
}
pipe((a, b) => a + b, (x) => x * 2)(3, 4); // 14
```

## Key points
- Mutating: push, pop, shift, unshift, splice, sort, reverse, fill. Copying (ES2023): toSorted, toReversed, toSpliced, with.
- `sort()` without a comparator compares items as strings but keeps their values: `[5, 1, 10].sort()` is `[1, 10, 5]`. Use `(a, b) => a - b`.
- `sort` mutates and returns the same array, so `nums === sorted` is true (same reference).
- `['10', '10', '10'].map(parseInt)` is `[10, NaN, 2]` because map passes the index as the radix.
- `includes` finds NaN (SameValueZero), `indexOf(NaN)` is -1.
- `flat()` removes one level from every item: `[[1, [2]], [3]].flat()` is `[1, [2], 3]`.
- `reduce` without an initial value starts with the first item and throws on an empty array.
- `forEach` ignores returned promises: use `Promise.all(arr.map(fn))` or `for...of` with await.

## Code
```js
function uniqueBy(array, key) {
  const seen = new Set();             // O(1) lookups, O(n) overall
  return array.filter((item) => {
    if (seen.has(item[key])) return false;
    seen.add(item[key]);
    return true;
  });
}
```
