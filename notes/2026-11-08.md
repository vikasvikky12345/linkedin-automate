## Key points
- A trace table has one column per variable and one row per loop round, with each value written after the round. It finds bugs you can't see by reading.
- A `for` loop runs init once, then check → body → update, repeated until the check is false.
- `length` counts items, while indexes run from 0 to `length - 1`. `str[str.length]` is always `undefined`, so a backward loop starts at `length - 1`.
- `out += undefined` adds the text 'undefined': a loop from `str.length` reverses 'abc' into 'undefinedcba'.
- Variable roles: counter, accumulator, best so far, flag, index. Naming the role explains the code.
- Edge cases only count if each one gets a decided output and a line of code (a guard clause at the top).
- Loop to method: `if (test) count++` is `filter(test).length`, `out.push(f(x))` is `map(f)`, and `total += x` is `reduce`.
- "Names of users older than 18" is filter, then map. Filter while the field still exists.

function capitalizeWords(input) {
  if (typeof input !== 'string') return '';
  let output = '';
  for (let i = 0; i < input.length; i++) {
    output += i === 0 || input[i - 1] === ' ' ? input[i].toUpperCase() : input[i];

}
