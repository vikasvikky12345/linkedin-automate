## Key points
- A trace table has one column per variable and one row per loop round, with each value written after the round. It finds bugs you can't see by reading.
- A `for` loop runs init once, then check → body → update, repeated until the check is false.
- `length` counts items, while indexes run from 0 to `length - 1`. `str[str.length]` is always `undefined`, so a backward loop starts at `length - 1`.
- `out += undefined` adds the text 'undefined': a loop from `str.length` reverses 'abc' into 'undefinedcba'.
- Variable roles: counter, accumulator, best so far, flag, index. Naming the role explains the code.
- Edge cases only count if each one gets a decided output and a line of code (a guard clause at the top).
- Loop to method: `if (test) count++` is `filter(test).length`, `out.push(f(x))` is `map(f)`, and `total += x` is `reduce`.
- "Names of users older than 18" is filter, then map. Filter while the field still exists.

# 2026-11-08: Logic Building L2 (Loops: which loop, and when)

Score 7/10, done.

## Key points
- Pick a loop with 3 questions: steps unknown → `while`. Index needed → `for`. Otherwise → `for...of` (arrays, strings) or `for...of Object.entries(obj)` (objects).
- If `i` is only ever used as `arr[i]`, you don't need the index: use `for...of`.
- `for...in` gives keys as strings: on `[10, 20, 30]`, `sum += i` builds '0012'. Never use it on arrays.
- `continue` skips the rest of this round; `break` leaves the loop at once (an `i++` after it never runs). A `continue` before `i++` in a `while` makes an infinite loop.
- `return` leaves the whole function, so a `break` right after it is dead code. `return` hands a value back; `console.log` only prints it.
- `while (num)` checks truthy/falsy: it stops at 0. So `countDigits(0)` needs its own case (0 has 1 digit).
- Return "nothing" in the promised type: index → -1, name → null, count → 0, list → [].
- A loop that returns `i` on the first match is `findIndex`; one that returns `arr[i]` is `find`.

## Code
```js
function firstNegativeIndex(nums) {
  if (!Array.isArray(nums)) return -1;
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] < 0) return i;   // stop early: the answer is ready
  }
  return -1;                     // -1, never 0: index 0 is a real position
}
// same thing: nums.findIndex((n) => n < 0)
```

```js
function countDigits(n) {
  if (!Number.isFinite(n)) return -1;
  if (n === 0) return 1;         // the loop would run 0 times for 0
  let count = 0;
  let num = Math.abs(n);
  while (num) {                  // unknown number of steps → while
    count++;
    num = Math.floor(num / 10);  // drop the last digit
  }
  return count;
}
```

```js
function topSubject(scores) {
  if (scores === null || typeof scores !== 'object' || Array.isArray(scores)) return null;
  let bestSubject = null;
  let bestScore = -Infinity;
  for (const [subject, score] of Object.entries(scores)) {
    if (score > bestScore) { bestScore = score; bestSubject = subject; } // > keeps the first on a tie
  }
  return bestSubject;
}
```
